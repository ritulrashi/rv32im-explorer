# RV32IM Microarchitecture Explorer

A cycle-accurate, parameterizable in-order RISC-V (RV32IM) pipeline model in C++20, verified against an independent golden functional simulator and correlated against SystemVerilog RTL.

> Work in progress. Phase 1 (golden ISS) design: [`docs/phase1-design.md`](docs/phase1-design.md).

Every number in this repository comes from a command recorded next to it. See [`docs/LIMITATIONS.md`](docs/LIMITATIONS.md) for what the model does not capture.
